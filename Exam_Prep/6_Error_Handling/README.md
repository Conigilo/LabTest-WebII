# 5. Error Handling & Data Validation (การคัดกรองข้อมูลก่อนเข้า Database)

หัวข้อนี้นักศึกษามักจะพลาดเวลาทำ Lab Test หรือทำโปรเจกต์จริง!
เวลาเราเขียน `app.post('/api/books')` เราจะรู้ได้อย่างไรว่าคนที่ยิง Request มา **"ส่งตัวเลขราคามาจริงๆ"** หรือ **"ส่งข้อความมั่วๆ (เช่น price: 'ห้าร้อยบาท')"** มาทำ Server เราพัง?

เราจึงต้องมีทหารยาม (Validation) และ พยาบาล (Error Handler) ครับ

### สิ่งที่ควรรู้สำหรับข้อสอบ
1. **Validation (การคัดกรองพฤติกรรม):**
   - การตรวจสอบเบื้องต้น: `if (!req.body.title) return res.status(400)`
   - การใช้ Library ยอดฮิต: **Joi** หรือ Zod (ในตัวอย่างเราใช้ Joi เพราะเขียนกฎง่ายและนิยมมาก)
2. **Global Error Middleware (การดักจับข้อผิดพลาดทั้งระบบ):**
   - แทนที่เราจะเขียน `res.status(500)` ซ้ำๆ ทุกบรรทัดที่พังใน `catch (error)` เราสามารถผูก Middleware พิเศษไว้ล่างสุดของ `app.js` ตัวเดียว เอาไว้ดัก Error ทุกชนิตที่หลุดมา

### วิธีทดสอบโฟลเดอร์นี้
```bash
node app.js
```
*จากนั้นเปิด Postman ยิง `POST http://localhost:3000/api/books` แบบไม่แนบอะไรไปเลย หรือแนบราคาติดลบไปดูครับ มันจะด่ากลับมาอย่างสวยงาม!*
